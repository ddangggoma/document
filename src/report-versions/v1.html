요약
  • 개념에이전트 자동화는 사람이 목표를 주면 AI가 계획·실행·점검을 이어서 수행하는 방식. 과제별 AI 자동화와의 차이는 과제 사이의 연결을 AI가 맡는다는 점
  • 현황소프트웨어와 반도체 설계가 선두, 소재와 바이오는 탐색 단계의 자동화와 자율 실험실 투자 단계
  • 사례AI가 쓴 논문의 심사 통과, 설계 검증 5주 → 하루, 후보 물질 42만 개 하루 탐색 등 화제 사례 다수
  • 한계실행은 자동화되나 연구 판단과 검증은 사람 몫. 독립 검증된 생산성 수치는 미확인
  • 인사이트자동 채점이 가능한 일부터 자동화 진전. 병목은 검증으로 이동, 준비의 핵심은 권한·검증·비용 통제

1. AI 에이전트 기반 R&D 자동화의 개념과 현황

R&D 자동화는 세 세대로 구분, 차이는 ‘누가 과제를 잇는가’

표 1. R&D 자동화의 세 세대
구분기존 자동화과제별 AI 자동화에이전트 자동화
대상정해진 반복 작업판단이 필요한 개별 과제여러 과제가 이어진 업무 흐름
방식사람이 짠 규칙과 스크립트 실행AI가 과제 하나를 입력에서 출력까지 수행AI가 목표를 받아 계획·실행·점검을 반복
과제 사이의 연결사람사람AI(사람은 승인)
사람의 역할설계, 운영과제 지정, 결과 확인목표 설정, 검토·승인
보기고속 실험 장비, 시뮬레이션 일괄 실행물성 예측, 구조 예측, 문서 초안 작성가설 → 실험 설계 → 실행 → 분석의 연속 수행
  • 당사는 과제별 AI 자동화 단계([ ]건 완료), 다음 단계는 자동화된 과제를 에이전트가 잇는 형태

맡길 수 있는 과제 길이의 확대와 제품 출시로 2026년 에이전트 자동화 본격화

  • 에이전트가 절반의 확률로 완수하는 과제 길이, 2025년 초 1시간대 → 2026년 초 약 12시간(독립 평가)1)
    • 80% 성공 기준으로는 약 1.5시간
  • R&D용 에이전트 제품 출시: Microsoft의 R&D 에이전트 플랫폼 정식 출시(2026년 6월), 반도체 설계 도구 3사의 에이전트 제품 발표(2026년)
  • 다만 기업 전반은 실험 단계, 에이전트 확대 적용은 어느 기능에서도 10% 이하(설문)2)

  2. McKinsey(2025. 11.)

  • AlphaEvolve(Google DeepMind): 수학 문제 67개 중 23개에서 기존 최선의 해 개선(논문)

3. 한계와 인사이트

한계 1. 실행은 되지만 연구 판단은 미달

  • 독립 평가에서 에이전트는 코드 작성과 실험을 사람 도움 없이 완수, 연구 결과물은 6점 만점에 2점과 1점(2026년 7월, 대상 2편)
  • 연구 에이전트의 정확도, 데이터 분석 85.5%·문헌 조사 82.1%, 종합·해석은 57.9%(개발사 측 평가)

한계 2. 효과 수치의 대부분이 자체 발표, 과장 사례도 반복

  • 숙련 개발자가 AI 도구를 쓸 때 작업 속도 약 19% 저하(2025년 자료, 독립 평가)
  • AI의 수학 미해결 문제 풀이 발표 삭제(2025년 10월), 신소재 발견 44% 증가 논문의 철회 요청(2025년 5월)

한계 3. 권한과 비용 통제의 실패가 실제 사고로

  • 에이전트가 운영 데이터베이스와 백업을 9초 만에 삭제(2026년 4월). Uber, 연간 AI 코딩 예산을 4월에 소진(보도)

인사이트

  • 자동 채점이 가능한 일부터 자동화 진전: 코드 테스트, 설계 검증, 수학 최적화
  • 분야 간 속도 차이는 검증에 걸리는 시간에서 발생: 코드는 수 분, 칩 검증은 수 일, 물질 합성은 수 주, 임상은 수 년
  • 병목이 실행에서 검증으로 이동, 사람의 역할은 작성에서 검토로 이동
  • 당사의 과제별 자동화 자산은 에이전트 자동화의 바탕. 과제를 잇기 전에 권한 설계, 검증 체계, 비용 한도 정비 필요

지켜볼 신호와 다음 결정

  • 독립 검증된 R&D 기간 단축 수치 공개, 자율 실험실 가동 성과, 에이전트가 설계한 칩의 양산 사례
  • 이번 보고의 결정 요청 사항은 부재. 2027년 1분기 재보고 예정
