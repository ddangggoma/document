# 보고서 작성 바이블

대기업 경영진에게 올리는 보고서를 위한 작성 기준서. 잡지형 HTML 한 파일(`index.html`)로 되어 있고, 브라우저에서 바로 열거나 A4로 인쇄할 수 있다.

## 구성

| 장 | 내용 |
|---|---|
| 1 원칙 | 경영진은 어떻게 읽는가, 좋은 보고서의 일곱 가지 조건 |
| 2 설계 | 결론 한 문장, 피라미드, 나누기, 주장하는 제목 |
| 3 흐름 | 자주 틀리는 보고서 흐름 열세 가지와 고치는 법 |
| 4 유형 | 열두 가지 보고서 유형의 틀 |
| 5 문장 | 개조식의 끝맺음, 어순, 호응, 정보의 흐름, 번역투, 피동, 명사 나열 |
| 6 낱말 | 비슷한 말 가려 쓰기, 확신의 정도, 빈말, 혼동어, 맞춤법 |
| 7 숫자와 모양 | 숫자 표기, 표와 그래프, 글꼴과 여백 |
| 8 퇴고와 보고 | 고치는 순서, 제출 전 점검표, 보고의 때, AI 활용 |
| 9 어휘 사전 | 보고서 낱말 2,220개(공통 2,000개, 기술전략 220개). 상황 묶음 → 분류 → 소분류로 찾아가기, 부분 일치·유사어·초성 검색, 빈도순·가나다순 |
| 기술전략팀 표현집 | 여덟 가지 상황의 문형, 견본 보고 두 가지. 사전에 기술전략 용어 묶음 추가 |
| 동향 보고서 쓰는 법 | 쓰는 순서, 출처 등급, 점검표. 별첨으로 「AI 에이전트 R&D 자동화 동향」 보고서와 해설 |
| 참고 자료 | 책, 연구, 지침 41종 |

## 고쳐 쓰기

```
src/chapters/*.html   장별 본문
src/style.css         디자인(색, 글꼴, 크기, 여백, 인쇄 판형)
src/app.js            어휘 검색
src/refs.json         참고 자료. 본문에서는 [[열쇠]]로 가리킨다
data/vocab.json       어휘 2,220개
python3 build.py      index.html 다시 만들기
```

## 알아 둘 점

- 별첨 동향 보고서의 수치는 2026년 11월 14일 웹 검색 요약을 근거로 했다. 원문을 직접 확인한 것은 한 건뿐이므로, 실제 보고 전에 붙임 표의 수치를 원문과 대조해야 한다.
- 권하는 예문은 모두 개조식이다. 항목 끝은 명사로 맺고 “~함, ~임”으로는 맺지 않는다. 어순과 호응을 다루는 5장의 예문과 이메일 견본만 “~습니다”로 맺었다.
- 사전은 `<vocab-browser>` 웹 컴포넌트다. 어휘는 JSON으로 실어 화면을 그린 뒤에 읽고, 낱말은 40개씩 이어서 그린다.
- 참고 자료의 내용은 출판사 소개, 서평, 저자 인터뷰, 논문 초록 같은 공개 자료로 확인했다. 책 본문과 한 줄씩 대조하지는 못했으므로 직접 인용은 싣지 않았다.
- 어휘 사전의 빈도는 말뭉치 통계가 아니고 어림한 값이다.
- 예문 속 회사와 숫자는 설명하려고 지어낸 것이다.
